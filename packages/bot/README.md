# @operad-io/bot

**The bot plugin.** A bot is a working directory, a default agent, skills, a speaker and an access profile. It is the parent of its chats. Optional: turn it on with `operad plugin enable bot`.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
