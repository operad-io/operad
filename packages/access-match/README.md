# @operad-io/access-match

**Access profiles matched against agent tool calls.** Says whether one tool call of an agent may run under an access profile's `denyPaths`, `denyCommands` and `askCommands`. The harnesses call it before a tool runs.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
