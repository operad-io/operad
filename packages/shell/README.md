# @operad-io/shell

**The base stage plugin.** Provides `shell/command`, `shell/check` and `shell/probe`: run one shell line, run a list of lines that stops at the first failure, and a probe a wait can call.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
