# @operad-io/engine

**The core of operad: flows, plugins and their records.** The kernel: flows, what waits for a person (pending), and history. Plugins are built on it with `definePlugin`.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
