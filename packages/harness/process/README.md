# @operad-io/harness-process

**Shared process and log helpers for the harness plugins.** The code the harness packages have in common: running a child process with a wall time and a stall limit, its logs, and an ACP client.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
