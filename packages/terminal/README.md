# @operad-io/terminal

**Terminals that `operad serve` keeps.** A command on a pseudo terminal in any folder, reached over HTTP from this machine. Part of [operad](https://github.com/operad-io/operad). A new home has it on; a home made before needs `operad plugin enable terminal`.
