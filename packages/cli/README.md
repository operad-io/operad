# @operad-io/cli

**The `operad` command.** The command line for operad: set up a home, run `operad serve`, open the terminal client, see what is pending, and run plugin commands. It needs [Bun](https://bun.com).

## Install

```sh
bun add -g @operad-io/cli
operad --help
```

`npm install -g @operad-io/cli` also works while `bun` is on your `PATH`. Then run `operad init` and `operad serve` or `operad tui`.
