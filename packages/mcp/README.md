# @operad-io/mcp

**The MCP server and channel.** `operad mcp` is an MCP server on stdio. A lead agent such as Claude Code reads pending, running and history, runs plugin commands and takes the actions `config.json` allows. It never takes your decision.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
