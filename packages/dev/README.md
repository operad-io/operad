# @operad-io/dev

**The dev plugin: plans and tasks on a repository.** Turns a request into planned work and follows each task through work, checks, review and merge, with you at the merge.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
