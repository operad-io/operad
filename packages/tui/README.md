# @operad-io/tui

**The terminal client.** `operad tui` shows what is pending and running, and opens an object beside the list. It talks to `operad serve` over the `/v1` interface and never opens the store itself.

This package is part of [operad](https://github.com/operad-io/operad). Most people install only [`@operad-io/cli`](https://www.npmjs.com/package/@operad-io/cli).
