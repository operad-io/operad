# Quickstart

`operad init` creates the home and checks the plugins. `operad serve` runs the loop for the home; `operad tui` opens the [terminal client](tui.md) and starts `serve` when none answers. `operad pending` lists what waits for a person and `operad list <type>` lists objects.

A complete workflow on a repository (a plan, tasks, a person at the merge) is in [Running operad on operad](../dogfood.md). The settings are in [config.json](config.md), the commands in [the command line](cli.md), and what to do when something does not work in [troubleshooting](troubleshooting.md).
