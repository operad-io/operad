# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue or discussion.

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe what you found, the operad and Bun versions, and the steps to
   reproduce it. Leave out real secrets.

Only the maintainers can see the report. We will reply there, work on a fix with
you, and say when it is released.

## Supported versions

Only the latest 0.x release gets security fixes. If you run an older one,
update first and check whether the problem remains.
